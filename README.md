# HydroRush— 2D Bullet Hell

## Description
HydroRush is a 2D top-down bullet hell game about water pollution. The player controls a living water droplet, avoids toxic projectiles, fights garbage enemies, and uses water-based abilities.
The objective is to dodge toxic projectiles, confront enemies linked to trash, and use water-based abilities to combat the pollution. The game features multi-directional movement, aiming and shooting mechanics, a "dash" ability for quick movement, and a purifying wave that helps eliminate threats. References such as *Touhou Project*, *The Binding of Isaac*, and *Bloody Hell* were taken into account; these served as points of reference for mechanics, HUD placement, and even the pixel-art style. For this project, we used assets found on Itch.io, as well as assets generated by AI—specifically ChatGPT and Gemini. The music was created using the free DAW BandLab, drawing inspiration from soundtracks like those of *Mega Man X* or various 8-bit games. We incorporated instruments such as synthesizers and pianos to evoke an "aquatic" sound, reminiscent of tracks like "Dire, Dire Docks" from *Super Mario 64*.

## Controls
- WASD or arrow keys: Move
- Mouse: Aim
- Left mouse button: Shoot
- Space: Dash
- Q: Activate the Purifying Wave when charged

## Environmental Message
HydroRush aims to raise awareness about water pollution through gameplay. By representing pollution as enemies and toxic projectiles, the game encourages players to reflect on the impact of waste on aquatic ecosystems. Thel player, embodied as a living droplet, symbolizes the importance of protecting and restoring natural water resources. 

## Main Features

- Fast-paced 2D bullet hell gameplay.
- Top-down player movement and aiming system.
- Purifying Wave special ability.
- Enemies inspired by different forms of pollution.
- Original soundtrack with aquatic-inspired themes.
- Pixel-art visual style.

## Installation

1. Clone the repository: git clone https://github.com/KairosNova/HydroRush.git
2. Open the project using Unity Hub.
3. Select the project folder.
4. Open the main scene inside the Assets folder.
5. Press Play in the Unity Editor.
