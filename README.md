# Aqua — 2D Bullet Hell

## Description
Aqua is a 2D top-down bullet hell game about water pollution. The player controls a living water droplet, avoids toxic projectiles, fights garbage enemies, and uses water-based abilities.
The objective is to dodge toxic projectiles, confront enemies linked to trash, and use water-based abilities to combat the pollution. The game features multi-directional movement, aiming and shooting mechanics, a "dash" ability for quick movement, and a purifying wave that helps eliminate threats. References such as *Touhou Project*, *The Binding of Isaac*, and *Bloody Hell* were taken into account; these served as points of reference for mechanics, HUD placement, and even the pixel-art style. For this project, we used assets found on Itch.io, as well as assets generated by AI—specifically ChatGPT and Gemini. The music was created using the free DAW BandLab, drawing inspiration from soundtracks like those of *Mega Man X* or various 8-bit games. We incorporated instruments such as synthesizers and pianos to evoke an "aquatic" sound, reminiscent of tracks like "Dire, Dire Docks" from *Super Mario 64*.

## Controls
- WASD or arrow keys: Move
- Mouse: Aim
- Left mouse button: Shoot
- Space: Dash
- Q: Activate the Purifying Wave when charged

## Project Structure
- Assets: Game assets, scenes, scripts, prefabs and audio
- Packages: Unity package dependencies
- ProjectSettings: Unity project configuration
