# Aqua — 2D Bullet Hell

## Description
Aqua is a 2D top-down bullet hell game about water pollution. The player controls a living water droplet, avoids toxic projectiles, fights garbage enemies, and uses water-based abilities.

## Technologies
- Unity 2D
- C#
- GitHub

## Controls
- WASD or arrow keys: Move
- Mouse: Aim
- Left mouse button: Shoot
- Space: Dash
- Q: Activate the Purifying Wave when charged

## Project Structure
- Assets: Game assets, scenes, scripts, prefabs and audio
- Packages: Unity package dependencies
- ProjectSettings: Unity project configuration
